Static diagrams, three ways

The same DiagramModel rendered as a fully static image, a pan-and-zoom viewer, and a live editable whiteboard. Static displays are ideal for docs, dashboards, and generated reports; the editable canvas is the whiteboard experience from the workspace.

1. Static display (DiagramView)

No pointer handling at all. Renders once, re-renders on model changes, exports PNGs.

const view = new DiagramView({ canvas, model, layout: new LayeredLayout({ direction: "LR" }) });

2. Read-only viewer (pan & zoom)

Drag to pan, wheel to zoom. Nodes cannot be moved or edited. Click still selects.

const engine = new LiveDiagramEngine({ canvas, model, interactions: "view" });

3. Editable whiteboard

Full editing: drag nodes, double-click to rename, right-drag reserved, wheel zooms.

const engine = new LiveDiagramEngine({ canvas, model, interactions: "edit" });
