CMU Serif subset from Computer Modern Unicode 0.7.0.

Bundled files:

- `cmunrm.ttf`: CMU Serif Roman, normal 400
- `cmunti.ttf`: CMU Serif Italic, italic 400
- `cmunbx.ttf`: CMU Serif Bold Extended, normal 700
- `cmunbi.ttf`: CMU Serif Bold Italic, italic 700
